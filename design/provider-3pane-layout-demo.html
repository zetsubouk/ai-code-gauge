结论与实现口径

推荐方案一，规则归一化为「呈现 N 家 → 布局」：1 家 = 单栏 360px；2 家 = 双栏 560px；3 家 = 双栏 + 排序末位跨双列（卡内并排）；4 家 = 2×2；≥5 家 = 2×N 内部滚动。
实现要点：CSS 加 .pane.span2 { grid-column: 1/-1 } 与其内部 .limits 双列；JS 在 render 时对「呈现面板中 providerOrder 末位」加 span2 类——与排序功能天然组合，用户通过 ↑↓ 即可决定谁占据底部宽位；预计代码量 ~15 行 + 单测 1 项。
